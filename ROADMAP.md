# Conduit Gateway Roadmap

Conduit Gateway is a research and prototyping project exploring a different approach to legacy system modernization.

Rather than granting direct access to systems, Conduit Gateway focuses on outcome-based access, policy-driven routing, dynamic conduits, and controlled data exposure. The objective is to allow users and applications to consume business outcomes while minimizing visibility into the underlying infrastructure.

## Long-Term Vision

Traditional architectures often expose systems and then attempt to restrict access.

Conduit Gateway explores the opposite approach:

1. Keep systems isolated.
2. Build temporary conduits on demand.
3. Validate requests through policy-driven routing.
4. Assemble approved outcomes.
5. Return only the information required.
6. Destroy the route.

Users should access outcomes, not systems.
